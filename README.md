# Gamer Store

A modern, dazzling, and portable gamer store website built with plain HTML, CSS (Tailwind CDN), and Vanilla JavaScript.

## Features
- **Dazzling Modern UI:** Professional gamer aesthetic with high-quality animations and transitions.
- **Multi-language Support:** Full Arabic (RTL) and English (LTR) integration.
- **Theme Management:** Dark and Light modes.
- **Full E-commerce Flow:** Login, Registration, Personalized Welcome, Product Catalog, Shopping Cart, and Checkout.
- **Zero Dependencies:** Runs directly in any web browser without installation or build steps.

## How to use
Simply open `index.html` in any web browser.
